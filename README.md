# EPlusSimple

EPlusSimple is a Windows-oriented building-energy simulation workflow built around EnergyPlus. Users prepare structured Excel or GRM input files, and EPlusSimple converts them into EnergyPlus models, runs the simulation, checks input problems, and summarizes the results.

## Main entry points

- **EPlusSimpleLauncher.exe**: desktop launcher for Excel/GRM comparison workflows
- **EPlusSimpleCLI.exe**: command-line interface for simulation, conversion, database lookup, and Excel input checking
- **run.cmd**: repository-level developer dispatcher for setup, build, release, and local Python tasks

## Developer command dispatcher

Run repository tasks through `run.cmd` from the repository root.

```bat
run help
```

Common commands:

```bat
run setup [options]
run build-go [options]
run release [options]
run py [python arguments]
run python [python arguments]
```

A PowerShell or Python script can also be called by path.

```bat
run scripts\setup\setup.ps1 -SkipGo
run scripts\dev\regressiontest.py
```

Calling `run` without arguments opens a PowerShell session rooted at the repository.

```bat
run
```

### Embedded Python helper

Open an interactive console with `epsimple` and `idragon` already imported:

```bat
run py -i
```

Pass raw Python arguments after `--`:

```bat
run py -- -c "import epsimple; print(epsimple.__version__)"
```

## Setup

Prepare the repository-local Python, EnergyPlus, Korean TMY, and Go runtimes:

```bat
run setup
```

Common setup options:

```bat
run setup -Force
run setup -SkipRequirements
run setup -SkipWeather
run setup -SkipGo
run setup -SkipRequirements -SkipGo
```

Installed locations:

```text
runtime\PythonV3-12-7
runtime\EnergyPlusV24-2-0
runtime\Weather\TMY
runtime\Weather\AMY
runtime\GoV1-26-3
runtime\.go
```

The setup script does not require a system-wide Python, EnergyPlus, or Go installation.

To reset the runtime completely:

```bat
rmdir /s /q runtime
run setup
```

## Build

Build the two Windows executables:

```bat
run build-go
```

After cloning the repository for the first time, or after changing `go.mod` or `go.sum`:

```bat
run build-go -Tidy
```

Generated files:

```text
EPlusSimpleCLI.exe
EPlusSimpleLauncher.exe
```

These executables are build artifacts and should not be committed.

## Launcher

Start the desktop launcher:

```bat
EPlusSimpleLauncher.exe
```

The launcher supports:

- one pre-retrofit input
- zero or more post-retrofit inputs
- Excel/GRM input checking before simulation
- parallel execution where available
- progress display
- monthly graphs and detailed tables
- CSV export of detailed results

Temporary launcher job files are written under `logs\launcher-jobs` and cleaned automatically.

## CLI

Show available commands:

```bat
EPlusSimpleCLI.exe --help
```

### Run a simulation

GRM input:

```bat
EPlusSimpleCLI.exe run -i "C:\path\model.grm"
```

Excel input:

```bat
EPlusSimpleCLI.exe run -i "C:\path\model.xlsx"
```

Specify a GRR output path:

```bat
EPlusSimpleCLI.exe run ^
  -i "C:\path\model.grm" ^
  -o "C:\path\result.grr"
```

When `-o` is omitted, the result is written beside the input with the `.grr` extension.

### Check Excel inputs

```bat
EPlusSimpleCLI.exe debug ^
  -i "C:\path\before.xlsx" "C:\path\after.xlsx"
```

Use multiple workers:

```bat
EPlusSimpleCLI.exe debug ^
  -i "C:\path\before.xlsx" "C:\path\after.xlsx" ^
  -w 4
```

The debug command returns `CLEAR`, `WARNING`, or `SEVERE` with detailed records.

### Convert input formats

```bat
EPlusSimpleCLI.exe convert "C:\path\model.grm" -d idf
```

Use `EPlusSimpleCLI.exe convert --help` for the available source and destination options.

### Read an embedded database entry

```bat
EPlusSimpleCLI.exe DB <datatype> -g <item-name>
```

Use `EPlusSimpleCLI.exe DB --help` for the accepted database names and arguments.

## Release

Create the release directory and ZIP:

```bat
set "RELEASE_VERSION=0.7.0"
run release -Version %RELEASE_VERSION%
```

Optional packaging checks:

```bat
run release ^
  -Version %RELEASE_VERSION% ^
  -SkipDocs ^
  -SkipRegressionTest
```

Outputs:

```text
dist\EPlusSimple_V<version>\
dist\EPlusSimple_V<version>.zip
```

The release package includes:

```text
EPlusSimpleCLI.exe
EPlusSimpleLauncher.exe
runtime\PythonV3-12-7\
runtime\EnergyPlusV24-2-0\
runtime\Weather\TMY\
src\
examples\
docs\                         # unless documentation is skipped
```

Regression test report updates use the repository runtime. The release Python runtime is created separately and installs only `scripts\release\requirements-release.txt`.

## Runtime isolation

Use the embedded Python runtime instead of a user-level Python installation.

```bat
runtime\PythonV3-12-7\python.exe -s -c ^
  "import epsimple, idragon; print(epsimple.__version__, idragon.__version__)"
```

Third-party modules should resolve under:

```text
runtime\PythonV3-12-7\Lib\site-packages
```

They should not resolve from a user-level path such as:

```text
C:\Users\<user>\AppData\Roaming\Python\Python312\site-packages
```

## Weather data

Korean TMY files are installed under:

```text
runtime\Weather\TMY
```

Check the installed EPW files:

```bat
dir /s /b runtime\Weather\TMY\*.epw
```

To reinstall weather data while keeping the existing Python and Go setup:

```bat
run setup -SkipRequirements -SkipGo
```
